## Phase 1 — 回測基礎設施 + 策略驗證

**目標**：用真實歷史資料驗證 EMA10/60 15 分鐘策略是否具備統計上的正報酬。

**實作項目**：
- [ ] `src/twquant/events.py`：事件型別
- [ ] `src/twquant/data/`：TAIFEX CSV loader、1m → 15m 聚合、連續合約串接
- [ ] `src/twquant/strategies/ema_crossover.py`：策略實作
- [ ] `src/twquant/risk/`：基本風控（部位大小、Kill Switch）
- [ ] `src/twquant/execution/backtest.py`：模擬撮合（含滑價、費用）
- [ ] `src/twquant/portfolio/`：部位與權益追蹤
- [ ] 回測 CLI：`python -m twquant.backtest run ...`
- [ ] HTML 績效報告
- [ ] 單元測試覆蓋率 ≥ 70%
- [ ] Walk-forward 分析工具

**資料**：回補 2018–2025 1 分 K，產出 15 分鐘連續合約序列

**通過條件**（見 `BACKTEST.md` § 目標門檻）：
- Sharpe ≥ 1.0
- Calmar ≥ 0.5
- MDD ≤ 30%
- 樣本外期間（2024–2025）績效不顯著劣於樣本內
- Walk-forward 累計 Sharpe ≥ 0.7

**未通過** → 回 Strategy 層思考：加濾網、換商品、換週期

**時程**：2–3 個月（週末時間）

## Phase 2 — 模擬交易（Paper Trading）

**目標**：在真實市場環境下驗證「程式運作穩定性」與「訊號時效」，不涉及真錢。

**實作項目**：
- [ ] Shioaji 即時 quote 接入
- [ ] Tick → 15m K 棒即時聚合
- [ ] Live Executor（模擬模式：發送訊號但不真實下單）
- [ ] 日盤 + 夜盤連續運行
- [ ] 斷線自動重連
- [ ] 狀態持久化（重啟後能續跑）
- [ ] Telegram 告警
- [ ] 每日績效報表自動寄送

**運行時長**：**連續 3 個月**，無重大中斷

**通過條件**：
- 實際訊號時間 vs 回測訊號時間差 ≤ 30 秒
- 無因程式錯誤導致遺漏訊號
- 累計停機時間 ≤ 2%（約 < 2 交易日）
- 模擬績效與回測預期大致吻合（月報酬落在回測 1 std 內）

**時程**：3–4 個月

## Phase 3 — 小額實盤

**目標**：真金白銀驗證，規模極小，容錯用。

**資金規模**：NT$200,000 – NT$500,000 / 交易 MXF 1 口

**實作項目**：
- [ ] Shioaji 實盤下單
- [ ] 訂單生命週期管理（送出、成交、拒單、部分成交）
- [ ] 部位對帳（每分鐘 vs 券商）
- [ ] 人工 kill switch
- [ ] 完整的交易紀錄 DB

**運行時長**：**連續 6 個月**

**通過條件**：
- 實際成交與模擬成交差異 < 0.3%（扣除滑價）
- 無「系統認為有單、券商沒單」之類的不一致
- 月報酬為正（至少 4/6 月）
- 最大回撤 < 15%

**時程**：6–9 個月

---

## Phase 4 — 規模化 + 優化

**目標**：擴大規模、穩定獲利、累積統計顯著性。

**資金規模**：逐步放大至專戶上限（單策略上限建議 NT$2M 以內）

**優化方向**：
- [ ] 參數微調（以 walk-forward 結果為依據）
- [ ] 加入做空（對稱邏輯）
- [ ] 加入過濾器（趨勢強度、成交量、大盤濾網）
- [ ] 動態部位大小（依波動調整）
- [ ] 遷移到 VPS（Docker 部署）
- [ ] PostgreSQL + TimescaleDB

**運行時長**：12–24 個月

**通過條件**：
- 年化報酬 ≥ 10%
- Sharpe ≥ 1.2
- 任意 12 個月區間報酬為正 ≥ 80%

**時程**：1–2 年

---

## Phase 5 — 多策略投組（長期）

**目標**：分散單一策略風險，建立穩健的多策略組合。

**策略類型考慮**：
- **趨勢類**：EMA 交叉（已有）、海龜法則
- **均值回歸**：RSI、布林通道
- **波動擴張**：ATR 突破、Keltner Channel
- **跨時間週期**：日線趨勢 + 小時進場
- **跨商品**（後期）：電子期、金融期、美股期貨

**設計原則**：
- 各策略彼此相關性 < 0.5
- 每策略資金配置依 Sharpe / 波動率動態調整（risk parity）
- 組合層級再加一層風控（總 MDD 上限）

**時程**：3–5 年

---

## 長期願景（Year 10–20）

- 累積資金規模能產生「可覆蓋基本生活費」的月現金流
- 系統夠穩定，每月人工維運時間 ≤ 10 小時
- 建立個人的量化研究流程與工具組，成為終身技能
- 可選擇：保留為個人工具／發展成小型基金／開源部分工具

## 里程碑（可量化）

| 年份 | 里程碑 |
| --- | --- |
| Y1 | Phase 0–3 完成，小額實盤 6 個月績效為正 |
| Y2 | Phase 4 放大規模，穩定運作 |
| Y3 | Phase 5 啟動，多策略上線 |
| Y5 | 年化報酬 ≥ 12%，累計報酬 ≥ 50% |
| Y10 | 資金規模 × 報酬 ≥ 年薪一半（被動收入概念成形） |
| Y20 | 財務獨立選項（FIRE optional）|

## 反里程碑（何時該停）

若連續發生以下情境，應嚴肅考慮停止：
- 任何 Phase 停留 > 預期時程 × 3
- 實盤連續 12 個月負報酬
- 系統整體 MDD > 40%
- 生活或健康因本專案顯著受影響

**停下來 ≠ 失敗**。寧可放棄也不讓它傷害生活。
